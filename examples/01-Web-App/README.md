# Contoh Laporan: Web Application (React & Node.js)

Folder ini berisi sampel struktur dan metadata untuk laporan projek aplikasi web modern.

## Detail Project
- **Judul**: Pengembangan Sistem Informasi Manajemen Tugas Berbasis Web React dan Node.js
- **Tipe Project**: Web Frontend & Backend REST API
- **Komponen Utama**:
  - `metadata.yml`: Pengaturan judul, penulis, dan dosen pengampu.
  - `chapters/`: Konten laporan per bab.
  - `Laporan-Web-Example.pdf`: Berkas PDF hasil kompilasi.
